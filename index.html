How the status is decided

Queue utilization = queue length / capacity x 100. Packet loss = dropped / generated x 100.
High Congestion: utilization ≥ 80% or loss ≥ 5%. Moderate Congestion: utilization ≥ 40% or any packet dropped. Normal: otherwise.

Learn the terms

Network congestion
Packets arrive faster than a link or router can forward them, so queues build up.
Packet switching
Data is split into packets that share links and are forwarded one by one.
Router queue
A buffer holding packets waiting for transmission. Here it is finite and FIFO (first in, first out).
Bandwidth
The maximum rate a link can send data. Here it is the router transmission rate in packets/s.
Latency
Delay a packet experiences. Here, the time spent waiting in the queue.
Throughput
The rate at which packets are actually delivered.
Packet loss
Packets discarded because the queue was full (tail drop).
Congestion control
Mechanisms such as TCP slowing its sending rate when loss or delay appears. This project does NOT implement TCP; it only shows the problem that such mechanisms solve.
